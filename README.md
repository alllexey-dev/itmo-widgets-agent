Маленькая фоновая программа, которую вы запускаете на своём ноутбуке, NAS или сервере. Она получает
события от сервера [ITMO.Widgets](https://github.com/alllexey-dev/ITMO.Widgets) и действует от вашего
имени в своей сессии My ITMO: главное - записывает на физкультуру из очереди, когда телефон этого сделать
не может (например, на iPhone без пушей).

Один статический бинарник без зависимостей, в простое занимает несколько мегабайт памяти.

> Закрытая бета: сервер включает агента только пользователям из списка. Чтобы попасть в него, напишите в
> [@itmowidgets](https://t.me/itmowidgets).

```text
ITMO.Widgets agent dev · nas
────────────────────────────────────────────────────────────
Состояние

Сервер            ● на связи
Сессия ИТМО       действует до 13.11 14:16 (ещё 29 дн.), ISU 123456, обновлена 13 мин назад
Последний опрос   1 с назад

Последние события
  14.10 14:36  физкультура: свободное место
  14.10 12:16  физкультура: автозапись
  13.10 13:16  друзья

Запись на физкультуру
  14.10 14:36  занятие 15.10 19:16, своб. место  мест нет, ждёт в очереди
  14.10 12:16  занятие 16.10 16:16, автозапись  записан

Журнал
  time=14:16:02 level=INFO msg="agent started" cursor=0

[s] обновить вход в ИТМО   [u] отключить   [q] выйти
```

## Что делает

- записывает на занятие из вашей очереди на физкультуру, когда сервер сообщает о свободном месте:
  перепроверяет очередь, смотрит, не записаны ли вы уже, и записывается;
- сообщает серверу результат: запись удалась, ИТМО отказал (запись в очереди отменяется) или мест
  нет (запись остаётся в очереди);
- присылает уведомления через [ntfy](https://ntfy.sh), если задан `IW_NOTIFY_NTFY_URL`: запись,
  отказ, заявки в друзья, закончившийся вход в ИТМО.

## Чего не делает

- не опрашивает расписание и свободные места сам: действует только по событиям сервера;
- не делает больше 60 запросов в час к ИТМО;
- не трогает ваши другие входы в ИТМО (телефон, браузер): завершает только свой собственный, когда вы
  отключаете агента (`unpair` или «Отключить» в приложении);
- не записывает других людей. Один агент - один аккаунт, только свой.

## Установка

Нужен телефон с ITMO.Widgets, где вы уже вошли, и доступ к бете (см. выше).

Linux и macOS, в терминале:

```sh
curl -fsSL https://raw.githubusercontent.com/alllexey-dev/itmo-widgets-agent/main/install.sh | sh
```

Windows, в PowerShell:

```powershell
irm https://raw.githubusercontent.com/alllexey-dev/itmo-widgets-agent/main/install.ps1 | iex
```

FreeBSD (`fetch` есть в базовой системе, `curl` не нужен):

```sh
fetch -qo - https://raw.githubusercontent.com/alllexey-dev/itmo-widgets-agent/main/install.sh | sh
```

Скрипт ([install.sh](install.sh), [install.ps1](install.ps1)) берёт последний релиз, сверяет SHA-256 с
`SHA256SUMS`, спрашивает, запускать ли агента в фоне как службу, и сразу переходит к подключению: показывает
QR-код для телефона (шаги ниже). Запущенный повторно, он показывает меню: обновить, подключить к телефону,
включить или выключить службу, посмотреть статус и логи, удалить.

Docker:

```sh
curl -O https://raw.githubusercontent.com/alllexey-dev/itmo-widgets-agent/main/compose.yaml
docker compose run --rm agent pair
docker compose up -d
```

Куда скрипт кладёт файлы и где логи в каждой системе, его флаги для запуска без терминала и установка
бинарника вручную: [docs/install.md](docs/install.md).

## Подключение

Скрипт установки начинает подключение сам. Вручную его запускает `itmo-widgets-agent pair`: команда
показывает QR-код и ссылку. Ссылка действует 2 минуты, не пересылайте её.

1. На телефоне: ITMO.Widgets -> Профиль -> «Устройства» -> «Подключить устройство» -> отсканируйте QR.
   Можно навести обычную камеру телефона или вставить ссылку.
2. Проверьте, что телефон показывает этот агент, выберите, что агенту можно, и нажмите «Продолжить».
3. Телефон откроет вход ITMO.ID в отдельном окне: войдите там. Это новый вход только для агента, пароль
   остаётся на телефоне. Агент получает лишь свой refresh-токен, зашифрованный ключом, который есть только у него.
4. Агент один раз обновит токен, напишет «Подключено» и сохранит токен подключения и сессию (права 0600).

Если запустить `itmo-widgets-agent` в терминале без токена, он сам откроет экран подключения. Уже
подключённый агент `pair` не подключит второй раз: `renew` обновит вход в ИТМО, `unpair` отключит агента.

Вход в ИТМО живёт не больше 90 дней с момента входа на телефоне, сколько бы агент его ни обновлял. Срок
показывают `status` и экран, а приложение напомнит за неделю. Когда вход закончится или его закроют (например,
«Завершить» на id.itmo.ru), агент пришлёт уведомление, перестанет записывать и отдаст запись телефону.
Обновите вход, не перезапуская агент:

```sh
itmo-widgets-agent renew
```

`renew` показывает такой же QR; на телефоне: Профиль -> «Устройства» -> агент -> «Обновить вход». Доступ и
настройки агента не меняются, телефон завершает старый вход, агент тоже.

## Команды

Все команды запускаются как `itmo-widgets-agent <команда>`, например `itmo-widgets-agent status`.

| Команда | Что делает |
|---|---|
| `run` или без команды | Работает: получает события и записывает на физкультуру |
| `pair` | Подключает агента с телефона по QR или ссылке |
| `renew` | Обновляет вход агента в ИТМО (раз в 90 дней или после закрытия) |
| `status` | Показывает состояние и последние строки журнала |
| `attach` (`watch`) | Открывает экран запущенной службы; `q` закрывает экран, агент продолжает работать |
| `unpair` | Отключает агента: завершает его вход в ИТМО, отзывает подключение, удаляет токен и сессию |
| `health` | Код выхода 0, если агент работает |
| `version` | Показывает версию |

В терминале `run`, `pair` и `renew` рисуют экран с состоянием, как выше; в Docker и в службе агент пишет
обычные логи. Клавиши экрана, `attach` и коды выхода: [docs/usage.md](docs/usage.md).

## Настройки

| Переменная | По умолчанию | Что это |
|---|---|---|
| `IW_BACKEND_URL` | `https://widgets.alllexey.dev` | сервер ITMO.Widgets |
| `IW_STATE_DIR` | `/data` или папка настроек | где лежат файлы агента |
| `IW_AGENT_TOKEN_FILE` | `$IW_STATE_DIR/agent-token` | токен подключения |
| `IW_FEATURES` | `sport,friends` | что включено; `pair` просит у телефона права под эти функции |
| `IW_NOTIFY_NTFY_URL` | нет | топик ntfy, например `https://ntfy.sh/my-long-random-topic` |
| `IW_AGENT_NAME` | имя машины | как агент называется в «Устройствах»; задаётся при `pair` |
| `IW_UI` | `auto` | `tui` - экран, `plain` - логи, `auto` - экран, только если запущен в терминале |
| `IW_LOG_LEVEL` | `info` | `debug`, `info`, `warn` или `error` |

Те же ключи можно записать в `$IW_STATE_DIR/agent.env` строками `KEY=VALUE`; переменные окружения
важнее файла.

## Приватность

- У агента свой вход в ITMO.ID, отдельный от телефона: на id.itmo.ru он виден отдельной строкой, и
  закрыть его можно, не трогая телефон. Пароль агент не видит: вход делает телефон.
- Токен ИТМО хранится только на вашей машине (`session.json`, права 0600). Сервер ITMO.Widgets его
  не видит: при подключении телефон передаёт сессию зашифрованной, ключ есть только у агента. Сервер
  знает только идентификатор входа (`sid`) и его срок, чтобы телефон мог его завершить.
- К серверу ITMO.Widgets агент ходит со своим токеном подключения (`iwc_...`), а не с токеном ИТМО, и
  только туда, где ему разрешено (физкультура, друзья).
- «Отключить» в «Устройствах» сразу закрывает агенту доступ к серверу, а телефон завершает его вход в
  ИТМО. Если телефон не смог, это сделает сам агент на следующем запросе: завершит свой вход, удалит токен и
  сессию и остановится с кодом 3.
- В логах и на экране нет токенов, имён и названий занятий; всё, что похоже на токен, логгер дополнительно
  маскирует.
- В каждом запросе к серверу ITMO.Widgets агент передаёт в заголовке `X-Client` данные сборки (версия,
  коммит, канал, источник) и ОС с архитектурой. Сервер хранит их по подключению для статистики клиентов
  у администратора (ADR 0034 в ITMO.Widgets) и удаляет через 180 дней после последнего использования и
  вместе с аккаунтом.
- Сессия даёт полный доступ к My ITMO, пока её не завершат. Безопасность машины, где запущен агент, на вас.
- Публичный ntfy.sh видит текст уведомлений. Лучше свой сервер ntfy или топик с длинным случайным
  именем.

## Ограничения

- Вход в ИТМО живёт не больше 90 дней: потом `renew`.
- Пока агент на связи, записью на физкультуру занимается он, а не телефон. Если агент выключен
  больше трёх минут или без сессии ИТМО, записывает телефон.

## Разработчикам

Сборка, тесты и устройство проекта: [CONTRIBUTING.md](CONTRIBUTING.md).

К ИТМО агент ходит своим минимальным клиентом: обновление токена ITMO.ID, выход из своего входа, список
записей на физкультуру и запись на занятие, больше ничего. Это осознанное исключение из правила "только
[my-itmo-api](https://github.com/alllexey-dev/my-itmo-api)": my-itmo-api остаётся эталонной реализацией,
форматы запросов и ответов сверяются с ним.
